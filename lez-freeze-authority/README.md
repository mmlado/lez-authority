# lez-freeze-authority

Freeze authority for LEZ actor programs (LEZ 0.4). The program's admin appoints and revokes a freeze authority, which freezes the whole program or a single account and releases it again. It is a second role of [lez-authority](https://github.com/mmlado/lez-authority), beside the admin of [lez-admin-authority](https://github.com/mmlado/lez-admin-authority), in a pure Rust library with no SPEL dependency.

Status: in development, no release yet. The v0.2.4 line lives in [spel-freeze-authority](https://github.com/mmlado/spel-freeze-authority) and stays as it is.
