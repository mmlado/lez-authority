# lez-freeze-authority

Freeze authority for LEZ actor programs (LEZ 0.4). The program's admin appoints and revokes a freeze authority, which freezes the whole program or a single account and releases it again. It is a second role of [lez-authority](../README.md), beside the admin of [lez-admin-authority](../lez-admin-authority/README.md), in a pure Rust library with no SPEL dependency.

Status: in development, no release yet. Its first release is 0.3.0, with lez-authority and lez-admin-authority. The v0.2.4 line lives in [spel-freeze-authority](https://github.com/mmlado/spel-freeze-authority) and stays as it is.
