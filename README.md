# lez-authority

Authority primitives for LEZ actor programs (LEZ 0.4): the holder slot with nominate and accept, renounce, and the seat routing that admin and freeze share. Policy-free, no notion of admin or freeze lives here. No SPEL dependency.

Status: pre-alpha, nothing released yet. Pinned to logos-execution-zone `dev` at 7e3f7f7 (2026-10-24).

The v0.2.4 line lives in [spel-authority](https://github.com/mmlado/spel-authority) and stays as it is. First consumer: [lez-admin-authority](https://github.com/mmlado/lez-admin-authority).
